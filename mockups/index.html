For people who read the README first

Stable space names for an unstable macOS surface.

A tiny Swift/AppKit app that maps custom labels to Mission Control spaces and stays honest about private API tradeoffs.

Architecture

It names what macOS exposes, then stays out of the way.

Enumerate spaces

Reads display and space topology through CoreGraphics Services / SkyLight symbols.

Persist labels

Stores names in UserDefaults under the SpacesManager bundle id.

Confirm movement

Shows a transient HUD when the active space changes.

Built for a personal Mac workflow, not the Mac App Store.

Private API use is explicit, the build is raw swiftc, and release automation handles the signed zip plus appcast.

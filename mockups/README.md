# SpacesManager Website Mockups

Open `index.html` in a browser to compare the three directions:

- Product: image-led landing page with the menu-bar workflow as the hero.
- Install: lighter first-run and trust-focused page for download/install clarity.
- Technical: README-forward page for power users who care about private API tradeoffs.

The product UI is built in HTML/CSS so labels, menu rows, HUD text, and calls to
action can be edited directly. The hero background is a generated bitmap copied
into `assets/hero-workspace.png`.
